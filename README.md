# 🔐 Anti-Theft Locker System

## 📌 Project Overview
The Anti-Theft Locker System is a smart security project designed to protect valuable belongings from unauthorized access. It uses sensors, a microcontroller, and an authentication mechanism to detect suspicious activity and improve locker security.

## ✨ Features
- 🔒 Secure access control
- 🚨 Theft and tampering detection
- 🔊 Alarm notification
- 📱 Optional IoT-based monitoring
- ⚡ Real-time security monitoring
- 🛡️ Improved protection against unauthorized access

## 🛠️ Technologies Used
- Arduino / ESP32
- Sensors
- Buzzer
- Authentication system
- IoT connectivity

## ⚙️ Working
1. The user attempts to access the locker using the authentication system.
2. The system verifies the access.
3. If unauthorized activity or tampering is detected, the alarm is activated.
4. The system can also send an alert when IoT connectivity is enabled.

## 🎯 Objective
To develop an affordable and smart locker security system that can detect unauthorized access and provide immediate alerts.
